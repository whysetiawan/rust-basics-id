Lesson 1: Hello, Rust!

Tap ID if you do not understand a sentence. Read the English first.

Today: you make the computer say your words.

What is a program?

A program is a list of steps.

The computer does the steps, from top to bottom.

Like a cooking recipe. Step 1, then step 2, then step 3.

Your first Rust program

fn main() {
    println!("Hello, world!");
}

It looks strange. That is OK. Let us look at each part.

  • fnfn = function. A group of steps with a name.
  • mainmain = the start. Rust always starts here.
  • { }Curly brackets. The steps go inside. { = open, } = close.
  • println!print line. It shows text on the screen.
  • "..."Quotes. Your text goes between the quotes.
  • ;Semicolon. The end of one step. Like a full stop.

Challenge

Make a program that shows these 3 lines. Use your favorite football player.

My favorite player is Messi. He plays for Inter Miami. He is the GOAT!

Start with this code. Change ___ to your text.

fn main() {
    println!("My favorite player is ___.");
    println!("___");
    println!("___");
}
See the answer 
fn main() {
    println!("My favorite player is Messi.");
    println!("He plays for Inter Miami.");
    println!("He is the GOAT!");
}

GOAT = Greatest Of All Time.

Read the error

Programmers make mistakes all the time. It is normal.

Rust tells you the mistake in English. It is a free English teacher!

This code has no ! after println. Run it.

fn main() {
    println("Hello!");
}

You see an error like this (maybe with more lines):

error[E0423]: expected function, found macro `println`
EnglishIndonesia
errorkesalahan
expectedyang diharapkan / seharusnya
foundyang ditemukan
macroperintah khusus Rust, namanya selalu pakai !

Meaning: Rust expected a function, but found a macro. Fix: add ! like this: println!
