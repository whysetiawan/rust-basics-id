Today: you keep data in a box, then show it.

What is a variable?

A variable is a box with a name.

You put something in the box. Later, you use it again.

The label is the name. The thing inside is the value.

Make a box with let

let player = "Messi";
let goals = 3;
  • letlet = make a new box.
  • playerThe name of the box.
  • =Put this value in the box.
  • "Messi"Text needs quotes.
  • 3Numbers do not need quotes.

Show what is in the box

Write the box name inside { } in your text. Rust changes {player} to the value.

println!("{player} scored {goals} goals!");
Messi scored 3 goals!

Tap Next. Watch the boxes appear.

Try it yourself

Copy, open Rustfinity, delete the old code, paste, run.

fn main() {
    let player = "Messi";
    let goals = 3;
    println!("{player} scored {goals} goals!");
}

A box that can change: mut

Normally, a Rust box is locked. You cannot change the value.

Add mut to change it. mut = mutable = can change.

Example: HP in a game. An enemy hits you. Your HP goes down.

fn main() {
    let mut hp = 100;
    println!("HP: {hp}");
    hp = hp - 30;
    println!("Ouch! HP: {hp}");
}

Read the error

This code has no mut. Run it. What happens?

fn main() {
    let hp = 100;
    hp = hp - 30;
    println!("HP: {hp}");
}

You see an error like this:

error[E0384]: cannot assign twice to immutable variable `hp`
