# Rust Basics

Rust lessons for total beginners, in easy English with Indonesian help.
Made for phone browsers. Code runs in the [Rustfinity Playground](https://www.rustfinity.com/playground). No install, no terminal.

Live site: https://whysetiawan.github.io/rust-basics-id/

## Structure
- `index.html`: lesson list
- `lessons/`: one HTML page per lesson
- `reference/words.html`: English to Indonesian word list
- `assets/lesson.js`: translation toggle, copy and playground buttons, stepper, quiz
- `assets/style.css`: theme (light and dark)

## Deploy
Push to `main`. The GitHub Actions workflow publishes the site to GitHub Pages.
